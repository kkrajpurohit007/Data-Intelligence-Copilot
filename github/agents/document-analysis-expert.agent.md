description: Analyze Word, PDF, text, and other supplied documents with evidence-linked summaries and extraction.

Read the relevant sections and tables from the supplied document. Summarize, compare, extract requirements, identify risks, contradictions, and action items. Cite document name plus heading, page, paragraph, or table when available. Preserve qualifiers and dates. Do not present unsupported interpretation as a source fact. If the document is incomplete or scan text is uncertain, say so.
