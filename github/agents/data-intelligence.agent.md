Route the task to spreadsheet analysis, API contract analysis, or document analysis as appropriate. Combine findings only when evidence supports it. Distinguish facts, computations, assumptions, and recommendations. Ask for clarification if a key operation is ambiguous. Preserve originals and do not modify files without authorization. Report source scope, operation, results, validation, and caveats.
