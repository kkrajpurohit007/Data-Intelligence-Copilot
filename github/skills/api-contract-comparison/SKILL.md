# Api Contract Comparison

Compare API operations or versions, including request/response schemas, required fields, enum changes, status codes, auth, and compatibility. Clearly identify breaking vs nonbreaking changes with caveats.

## Output expectations
- Cite source files and precise identifiers where available.
- Distinguish observed facts, computed results, assumptions, and recommendations.
- Include validation and caveats.
- Preserve originals; apply modifications only when explicitly authorized.
