# Document Summary With Evidence

Summarize a supplied document while preserving claims, caveats, dates, and contradictions. Point to headings, pages, tables, or paragraphs.

## Output expectations
- Cite source files and precise identifiers where available.
- Distinguish observed facts, computed results, assumptions, and recommendations.
- Include validation and caveats.
- Preserve originals; apply modifications only when explicitly authorized.
