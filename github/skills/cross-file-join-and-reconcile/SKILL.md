# Cross File Join And Reconcile

Choose a defensible matching key, normalize only as justified, reconcile records, and report matches/unmatched/conflicts. Avoid fuzzy matching unless explicitly requested and disclose confidence.

## Output expectations
- Cite source files and precise identifiers where available.
- Distinguish observed facts, computed results, assumptions, and recommendations.
- Include validation and caveats.
- Preserve originals; apply modifications only when explicitly authorized.
