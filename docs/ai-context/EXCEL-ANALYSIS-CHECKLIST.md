# Excel analysis checklist

- Workbook name and relevant sheets
- Used range, headers, table names, hidden rows/columns if relevant
- Formula cells vs stored values
- Data types, units, date formats
- Filters and inclusion/exclusion rules
- Metric definitions, denominator, aggregation
- Missing values, duplicates, invalid values, outliers
- Row counts and reconciliation totals
- Cell/range or row-key evidence
- Preserve source; output separately unless authorized
